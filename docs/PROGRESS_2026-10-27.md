# 2026-10-27 看板交付

本轮完成基于当前数据库的四页只读看板，不将其等同于 P0 / P1 阶段整体完成。

## 已实现

- 首页：LH / JD / C 三品种卡片，真实主次合约、价格单位、同合约相邻入库日变化、链式 5 / 20 日指标、量仓变化、质量与覆盖状态。
- 重要变化：质量 / 缺失优先，其次换月，固定排序最多五项；可展开原始合约、来源、批次与质量证据。
- 主力历史：品种独立图、每次主力切换分段；A → B → A 也不跨段连线。
- 品种研究：真实合约选择、OHLC K 线（字段不齐退为收盘线）、独立成交量 / 持仓图、观测数选择、CSV 导出和窗口状态。
- 期限结构：当日与历史日对照，按交割年月排序；固定近远月合约对及样本类型选择，近月减远月；样本类型缺失观测处断线，显示样本数 / 预热状态与流动性。
- 日报与系统：失败日期也可选择，空库保留四个入口；独立展示运行、数据健康、AI 阶段及异常；可下载日报最新副本。
- AI 默认折叠，仅展示最近任务时间范围内明确完成品种的分析；无可核验结果时不回退旧分析。
- 本地刷新没有采集或 AI 副作用；保留显式补跑控制。390px 下三卡单列。

代码：`ui/app.py`（入口）、`ui/dashboard.py`（页面）、`ui/queries.py`（只读查询）、`ui/charts.py`（图表）。
